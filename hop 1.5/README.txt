Bible90 PWA (Multipage + Admin)

What you get:
- Pages: Home, Service, Giving, Gallery, Connect, Tracker, Admin
- Tracker: 90-day checklist (13–14 chapters/day), notes, streak, export/import
- Admin (local-only): create password, edit page content, manage gallery (URLs)

IMPORTANT (Login/Admin):
- This admin is local-only (per device/browser). If you need real login for multiple users, you will need a backend.

Deploy:
1) Upload all files to a folder on your server (HTTPS recommended)
2) Visit /index.html in Safari
3) Share -> Add to Home Screen

Files:
- index.html
- manifest.webmanifest
- sw.js
